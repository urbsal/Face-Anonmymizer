# Face-Anonymizer
This repo is mainly developed for face anonymizer project. 
### Source Code and Setup Instruction

The source code for the face anonymization application is written in Python. The application was developed and tested on Raspberry Pi OS using Raspberry Pi with pi camera (camera module). The goal of the application is to detect the human face in images and in real-time camera frames and anonymizes the detected faces. 

The application used the virtual environment called face_app_venv and python verison 3.15.5 was used in this environment.
